# Python Projects

A collection of Python programs written while learning Python in Class 12 (CBSE PCM + CS stream).
Built over 7 months (August 2025 – March 2026).

---

## Projects

More complete, multi-feature programs.

### Password Strength Checker
Checks the strength of a password based on length, uppercase, lowercase, digits, and special characters. Displays a detailed analysis report.

### Banking System
A menu-driven banking program with deposit, withdrawal, and balance display. Handles edge cases like negative amounts and overdraft.
> Built following a tutorial — logic understood and can be explained.

### Dice Roller
Rolls one or more dice and displays the result using ASCII art. Shows total of all dice.
> ASCII art referenced from a tutorial.

### Math Quiz
A simple math quiz game with a loading animation. Generates random addition questions and checks answers.

## Mini Programs

Smaller focused scripts, each practicing a specific concept.

| File | What it does |
|---|---|
| `calculator.py` | Basic calculator with +, -, *, / and division by zero handling |
| `number_guessing_game.py` | Guess a number between 1-100 with hints and guess counter |
| `rock_paper_scissors.py` | Play rock paper scissors against the computer with replay option |
| `countdown_timer.py` | Countdown timer that displays time in HH:MM:SS format |
| `typewriter_effect.py` | Prints any sentence letter by letter with a delay |
| `traffic_light.py` | Simulates a traffic light system using two functions |
| `discount_calculator.py` | Calculates discount and net payable amount based on shopping total |
| `login_system.py` | Login system with 3 attempts before account block |
| `arithmetic_progression.py` | Generates AP series, finds last term and sum |
| `fibonacci.py` | Generates Fibonacci sequence up to n terms |
| `student_marks_analyser.py` | Takes marks of 5 students, finds highest and average |
| `shopping_cart.py` | Add items and prices, displays total bill |
| `email_splitter.py` | Splits email addresses into username and domain |
